MARGINES — wersja w czystym HTML, CSS i JavaScript
====================================================

Jak otworzyć:
  Kliknij dwukrotnie plik index.html — strona otworzy się w przeglądarce.
  Nic nie trzeba instalować. Można też wrzucić cały folder na dowolny hosting.

Struktura:
  index.html                 strona główna (interaktywne zdjęcie wnętrza)
  ksiazki.html               sklep z wyszukiwarką i filtrami
  ksiazka-*.html             strona pojedynczej książki (18 plików)
  kawiarnia.html             menu kawiarni
  wydarzenia.html            kalendarz wydarzeń
  blog.html, blog-*.html     Journal i artykuły
  o-nas.html, kontakt.html
  css/bootstrap.min.css      Bootstrap 5
  css/style.css              wygląd MARGINES (kolory, czcionki, komponenty)
  js/data.js                 lista książek (tytuły, ceny, dostępność)
  js/script.js               koszyk, panele, menu, filtry, formularz
  img/                       zdjęcia

Koszyk zapamiętuje produkty w przeglądarce, ale jest pokazowy (bez płatności).
Formularz kontaktowy nie wysyła wiadomości.
